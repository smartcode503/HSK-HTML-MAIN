# HSK 真题数字化材料

这个文件夹用来把一套 HSK 2.0 真题做成可以发给学生的学习和测验材料。覆盖三级、四级、五级、六级。听力和阅读各做一份网页。书写不收进这些材料。

老师准备试卷。助手先下载答案和听力文稿，再生成 Word 讲义和两份网页。没有听力录音也继续做。成品放在老师指定的目录，不放在本文件夹里。

## 一套卷子最后得到什么

按这个顺序产出：

1. `{卷号}-阅读解析.docx`  
   阅读讲义。英文说明为什么这题选这个、其他选项为什么不行。生词按 2012 年词汇表标级。听力原文和书写不写进这份 Word。
2. 答案 PDF、听力文稿 PDF  
   先下载到输出目录，听力页靠这两份来写。常见名字是 `{卷号}答案.pdf`、`{卷号}听力材料.pdf`。录音不在这一步。
3. 两份三一学校练习页  
   - `{卷号}-听力-带有答案解析-可输出 PDF-三一-{日期}.html`
   - `{卷号}-阅读-带有答案解析-可输出 PDF-三一-{日期}.html`

日期写成八位，例如 `20261014`。

## 怎么让助手做

把试卷路径和输出目录一起说清楚，例如：

```text
用 /Users/yinshijin/Desktop/我的 skill/HSK-HTML-MAIN
试卷：/路径/H41006.pdf
输出到：/路径/测试输出结果
```

也可以在对话里运行 `/HSK-HTML-MAIN`，后面跟上试卷路径和输出目录。

只要阅读讲义时，说清楚「只要阅读解析」。助手写完 Word 就停，不继续做网页。

同名的 `{卷号}-阅读解析.docx` 已经存在时，先问再覆盖。

## 学生打开网页之后

页面是印尼万隆基督教三一学校的登录页（SEKOLAH KRISTEN TRIMULIA，红色校名）。学生填写姓名和班级后做题。

- 交卷前看不到解析，也看不到听力原文或阅读里的讲解。
- 交卷后显示得分。成绩写入学校表格，字段是姓名、班级、得分、满分、切换页面次数。
- 右上角「输出」在交卷后下载成绩单 PDF。交卷前点它，只会提示先交卷。下载不再提交第二次成绩。
- 成绩单文件名是 `{姓名}-{日期}-{时间}-{卷号}听力-{分数}分.pdf`，阅读页把「听力」换成「阅读」。第一页是分数、用时和切屏次数，后面按题号列出题目、选项、学生的选择、正确答案和解析。

## 阅读怎么拆

一个单元是试卷上共享的一段材料：一组词、一组句子，或一篇短文。题号不能缺，也不能重复。

| 级别 | 听力 | 阅读 | 讲义里的主词表 | 更高词表 |
| --- | --- | --- | --- | --- |
| 三级 | 1–40 | 41–70 | HSK 3 | HSK 4–6 |
| 四级 | 1–45 | 46–85 | HSK 4 | HSK 5–6 |
| 五级 | 1–45 | 46–90 | HSK 4 和 5 | HSK 6 |
| 六级 | 1–50 | 51–100 | HSK 5 和 6 | 没有更高等级；超纲词单独列表 |

主词表只收这一级新出现的词。更低级别的词不重复列出。某一题真正用到、又不在 2012 表里的词，才放进超纲表。

各部分怎么分组、错项要写几条，写在 `references/paper-map.md`。四级排列顺序题只写两个学生容易排错的顺序，不把另外五种排法都写上。

## 这个文件夹里有什么

```text
HSK-HTML-MAIN/
├── README.md                 给老师看的说明（本文件）
├── SKILL.md                  给助手看的操作顺序
├── references/
│   ├── paper-map.md          三到六级阅读的题号和分组
│   ├── unit.md               阅读讲义每一单元要写哪些内容
│   └── pdf-export.md         成绩单按钮、文件名和核对方法
└── scripts/
    ├── hsk_vocab.py          查一个词或一段话的 2012 等级
    └── build_notes.py        把 notes.json 写成阅读解析 Word
```

助手先按 `references/unit.md` 写成 `notes.json`，再交给 `build_notes.py`。Word 的标题、色块和表格由脚本排版。脚本写完后不要再手改这份 docx。脚本会检查题号是否到齐、词的等级是否和官方表一致、四级排序题是不是正好两个错序。检查不通过就改 JSON，再跑一次。

网页上的阅读解析从这份 Word 抄来：为什么选它，以及每个错项为什么不行。听力解析根据听力原文和答案另写，不放进阅读 Word。


生成 Word：

```bash
python3 "/Users/yinshijin/Desktop/我的 skill/HSK-HTML-MAIN/scripts/build_notes.py" \
  /tmp/H41006-notes.json \
  -o "/输出目录/H41006-阅读解析.docx"
```

成功时脚本打印 `wrote …`，并写出单元数量。
